# Mixtape

A dependency-free browser music player. Open `index.html` in a browser to use it.

## What it does

- Search the included demo catalog
- Queue, shuffle, repeat, like, and play tracks
- Import audio files from your computer
- Load remote audio sources by editing the track list in `app.js`

The demo catalog uses SoundHelix sample audio URLs. A production version would connect the search field to a licensed music catalog API and use its playback rules.
